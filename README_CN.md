## 📌 项目简介

**Reduce Image Dimensions** 是一款简单易用的在线图像尺寸修改工具，旨在帮助用户快速调整图片像素分辨率（宽度与高度）并降低文件体积。无论你是需要满足严格的系统上传尺寸要求，还是为了提升网页加载速度，无需安装任何软件，直接在浏览器中即可轻松完成处理。

---

## ✨ 核心功能

* **📐 精准尺寸调整**：支持按像素或百分比自由调整图片的宽度与高度，可锁定宽高比避免变形。
* **⚡ 智能体积缩小**：在尽可能保持画面清晰的前提下，大幅减少图片占用空间（KB/MB）。
* **🔒 隐私与安全**：注重用户隐私，确保数据处理过程安全无忧。
* **🚀 免安装/全平台兼容**：纯 Web 界面，完美适配桌面端及移动端浏览器。
* **🎯 极简操作**：拖拽上传图片、设置目标尺寸、一键导出下载，三步完成。

## 🛠️ 常见使用场景

- **证件/表格上传**：快速修改照片像素尺寸，完美适配各类报名系统、签证及证件照上传要求。
- **网站与电商优化**：调整横幅与商品图尺寸，提升网页加载速度与 SEO 表现。
- **社交媒体配图**：精准修改图片宽高，适配各大社交平台及博客文章最佳尺寸。
